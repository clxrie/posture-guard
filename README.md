# PostureGuard

Real-time posture monitoring system that tracks your sitting 
distance using an ultrasonic sensor and visualizes posture 
patterns through an interactive web dashboard.

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Recharts
- Firebase Realtime Database
- Arduino Uno + HC-SR04

## Features (in progress)
- [x] Real-time distance display
- [x] Posture status alerts
- [x] Session timer
- [x] Posture scoring
- [ ] Historical analytics
- [ ] Daily/weekly trends
- [ ] Gamification (streaks, grades)
- [ ] Bilingual support (EN/KR)
